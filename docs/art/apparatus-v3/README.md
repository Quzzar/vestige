# Pedestal reference and revision

Three owner-supplied pedestal/plinth photographs, October 3, 2026, preserved unchanged:

- [Framed panel pedestal with stepped cap](pedestal-reference-1.png)
- [Weathered pedestal with central relief](pedestal-reference-2.png)
- [Pedestal with rosette ornament](pedestal-reference-3.png)

They guide silhouette, molding and side-panel ornament. No photograph pixels were copied into Minecraft textures. The current independently authored voxel models use vanilla texture references and incorporate original Amethyst rosettes and abstract cyan runic strokes.

[Current design and previews](../../design/apparatus-models.md) · [Model bundle](apparatus-models.zip)

The selected [construction recipes](../../design/material-crafting.md#construction-recipes) and [original recipe screenshots](../apparatus-v1/README.md) remain the construction reference. The bundle includes those inert authoring recipe files, with one-block outputs recorded. Runtime block/item registration, placement and station behavior remain future work. The names Stone Pedestal and Runic Pedestal remain current while "plinth" is an alternate considered by the owner.
