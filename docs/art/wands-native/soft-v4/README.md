# Softer wand artwork · review version

**October 7, 2026. Preview for owner review; not published or installed.** The owner found the previous native pixels too harsh. This pass reduces dark-outline and highlight contrast, replaces the export's extreme-colour selection with nondithered median-cut shade ramps, and reduces body contour coverage expansion from one-third to forty percent. The gold wraps stay visible with warmer shades. Material identities, characteristic bends/branches, common attachment and actual 16×16 size are retained.

The built-in image tool edited the source atlas as [wand-components-v4.png](../source-art/wand-components-v4.png). The [complete prompt and production conversion notes](../source-art/prompts-v4.json) are saved. Native sprites have at most eight opaque colours per body and four per tip, hard alpha and one-pixel clear outside borders. All 63 composed unions are checked for connectedness and padding. The five thread textures and item models are unchanged; this pass changes no casting, recipes or other gameplay.

`inventory/wands-and-threads.png` and `inventory/beside-vanilla-materials.png` are unedited Minecraft 1.21.1 / NeoForge 21.1.72 framebuffer captures using actual item stacks in the vanilla survival inventory renderer. They show the new exported sprites beside ordinary Minecraft items. The resource manifest pins all twenty loaded texture hashes. The temporary inventory harness is excluded from production compilation. `sprite-contact-sheet.png` is an enlarged nearest-neighbour inspection of the actual 63 PNG unions, not a game screenshot.

`verification.json` records palette/border checks, native frame and resource hashes, packaging, and complete compressed logs. Run `tools/author_wand_models.py --check` with Pillow to verify exact sprite/model drift and structural constraints. The [prior installed version](../faithful-v3/README.md) remains unchanged in the testing pack; this candidate remains uncommitted in the shared source and isolated wand checkout for design iteration.
