# Aligned slots and faint rotation hints

Built-in imagegen edits, `transparent_background: false`. The bitmap assets retain the paper, Plinths, Spellstone and inward arrows. Circular guides are separate UI overlays derived from the same coordinates used for item slots; a few ticks have a tiny bent stroke suggesting rotation. Four-slot seats share one radius; the eight-slot seats have separate inner/outer radii around one center. Earlier baked guide circles were not aligned and are superseded.
