## Platform and scope

Minecraft **1.21.1**, NeoForge **21.1.72**, Java **21**, one Gradle project under `src/`. Development runs co-load the sibling Kithkyn JAR and check matching platform versions. Curios and inherited compatibility dependencies are removed.

The project owner explicitly deferred native wands, discovery, and progression and requested deletion of inherited systems. The retired layer included wands/upgrades, books/workbench, discovery/XP tiers, legacy spell registry/casting, artifacts, world generation, recipes/loot, renderer/assets/sounds, attachments, networking, mixins, service-loader adapters, and data generators. The active source tree now contains the native spell framework and its bootstrap/tests. A local pre-removal working-tree backup was preserved; attribution remains in `CREDITS.md`/`LICENSE.md`.
