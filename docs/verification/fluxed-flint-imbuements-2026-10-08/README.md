# Fluxed Flint crafted imbuements

The owner authorized implementing Fluxed Flint imbuements on October 8. The existing four-offering recipe now supports Stabilized (Quartz Block in Dissentient Diamond’s socket) and Reinforced (Iron Block in either Netherite socket). Their complete combination is Braced. The plain route remains unchanged; the repair budget and intrinsic failure chance are 128 / 10%, 96 / 5%, 192 / 15%, and 144 / 7.5% respectively.

Selections use the shared bounded item data, immutable trait resolution and exact adjective catalog. Success copies the target and catalyst, changing only damage; canceled operations are free, and the first volatile trigger survives unchanged. Crafting retains socket materials. Malformed budgets, unknown selections and duplicate Reinforced contributions reject freely. Existing plain stacks need no rewrite or migration. All artwork, rarity and shimmer remain unchanged.

Verification results and delivery hashes are recorded in `verification.json`; native framebuffer evidence lives in `native/`.
