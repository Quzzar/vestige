# Fluxed Flint crafted imbuements

The owner authorized Fluxed Flint imbuements on October 8. The unchanged four-offering construction accepts **Quartz Block in Dissentient Diamond’s socket** for Stabilized and **Iron Block in either Netherite socket** for Reinforced. Both choices make Braced. Plain/Stabilized/Reinforced/Braced budgets are **128/96/192/144** repair points, with intrinsic Flint backfire chances **10%/5%/15%/7.5%**. These numbers are initial playtest tuning.

Shared bounded selections, immutable trait resolution and complete adjective naming preserve each choice once. Repairs copy the exact target and catalyst, changing only damage. Cancellations are free; the first volatile trigger survives unchanged. Socket materials remain installed. Duplicate Reinforced contributions, malformed budgets and recognized incompatible pairs reject freely. Existing plain stacks need no rewrite. Artwork, rarity and shimmer are unchanged.

**Verified:** 216 unit tests across 47 suites; all 372 required Minecraft tests with Kithkyn, including seven new Flint world cases; packaging; adjective/Spellshaping author checks and 490 leyline fixtures. The final co-loaded native client passes nine assertions and all five framebuffer frames were inspected. It repairs ten points with an actual Stabilized catalyst, retaining its imbuement and 96-point maximum while applying ten wear. All fifteen changed compiled classes and the loaded item assets match the installed JAR. The exact package is installed in **Kithkyn Testing**, with a verified timestamped backup; restart Minecraft to load it. `verification.json` pins the results and hashes. The attached [pull request](https://github.com/Quzzar/vestige/pull/6) records publication state.

Two early release builds overlapped compilation and reused incomplete local output; a fresh compilation without build-cache reuse resolved this. Initial native attempts were stopped while investigating loading, including a locked Mac. The new capture mode also activated the general spell recorder; excluding this mode fixes the collision. The final isolated native invocation succeeds. Raw logs and thread dumps are retained locally outside the repository and excluded from publication.

Optional JEI/EMI screens were not opened; all four public patterns are tested against the live recipe under every rotation and either Netherite offering. The frames show inventory sprites, native shimmer, repair lift/output and durability; no hovered tooltip is visible, so exact translated names/rarity/glint rely on assertions in the actual client. Survival economy remains playtest work. No post-crafting refill or upgrade route is implemented. Other chats’ unfinished Staff/art/equipment changes are excluded from this scoped release.
